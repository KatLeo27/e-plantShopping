# e-plantShopping

Paradise Nursery is a React-based shopping application for houseplants. The application allows users to browse different categories of plants, add plants to a shopping cart, manage quantities, and view the total cart amount.

## Features

- Landing page with background image and company information
- Product listing page with multiple plant categories
- Shopping cart with dynamic item count
- Add to Cart functionality
- Increase and decrease quantity of items
- Remove items from cart
- Redux Toolkit for state management
- Responsive and visually appealing UI

## Technologies Used

- React
- React Router DOM
- Redux Toolkit
- CSS

## Plant Categories

- Air Purifying Plants
- Indoor Plants
- Medicinal Plants

Each category contains six unique plants with images, prices, and descriptions.
